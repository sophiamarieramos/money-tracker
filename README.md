# Where Did My Money Go? 

Your money disappeared. Let's investigate. 

A playful yet powerful expense tracker with a "financial bestie" vibe. Track your spending, analyze your habits, and get cute insights about your money - all with a beautiful glassmorphism design! 

Features

Dashboard
- Weekly spending overview
- Category breakdown (Food, Shopping, Coffee, etc.)
- Spending trend meter
- Quick insights

Add Expenses
- Easy expense tracking
- 8 categories to choose from
- Auto-categorization
- Recent expenses list

Money Investigation
- Smart spending analysis
- Shopping alerts
- Coffee spending tracker
- Pattern detection

Wishlist
- Save items you're dreaming about
- Track how long items have been on your wishlist
- Easy remove option

Savings Goals
- Set financial goals
- Track progress with visual bars
- See estimated time to reach goals
- Add savings manually

Girl Math Calculator
- Justify purchases with "girl math"
- Calculate cost per use
- Get verdict: Approved or Think about it

Financial Wrapped
- Monthly summary like Spotify Wrapped
- Top spending category
- Most expensive day
- Most frequent purchase
- Financial personality

Multi-User Support
- Create account with username & password
- Each user has their own data
- Secure login/logout
- Data stored in localStorage

Reset Data
- Clear all your data with confirmation
- Perfect for starting fresh
